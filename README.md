# Калькулятор: уроки 1–5

Учебный проект группы 14+, KIBERone Ярославль. Собран так, что **каждый коммит это один шаг занятия** и каждый запускается.

## Как запускать

Из корня проекта, в терминале:

```bash
python main.py
```

Не через кнопку Code Runner: её вывод идёт в панель Output, а она только на чтение, и первый же `input()` падает с `EOFError: EOF when reading a line`.

## Как смотреть историю по шагам

```bash
git log --oneline              # список шагов
git show <хеш>                 # что именно поменялось на шаге
git checkout <хеш>             # отмотать проект на этот шаг
git checkout main              # вернуться в конец
```

Файлы уроков 4–5 запускаются **из своей папки**, а не из корня:

```bash
cd urok4
python read_example.py
```

Это не придирка: `open()` ищет файл относительно текущей папки терминала, а не относительно скрипта. Запуск из корня даёт `FileNotFoundError: example.txt` — проверено.

## Что проверено запуском

- `2`, `10`, степень → `1024.0`
- `5`, `0`, деление → «Ошибка: деление на ноль невозможно!»
- `привет` → «Ошибка: введено не число!»
- `9`, корень → `3.0`
- `-9`, корень → сообщение своего исключения

Уроки 4–5, прогон 18.09.2026: все пять файлов отрабатывают с кодом 0; «Моя библиотека» и «Список дел» показывают свои записи после перезапуска, то есть данные действительно переживают выход.

## Три ловушки Windows в уроках 4–5

Проверены запуском, все три вылезут на занятии.

- **`open()` без `encoding="utf-8"`** берёт на школьной машине cp1251. Русский текст запишется, но файл перестанет быть UTF-8: `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xce`. В методичке и на слайдах `encoding` местами опущен.
- **`csv.writer` без `newline=""`** даёт в файле `\r\r\n`. Две записанные строки читаются обратно как четыре, каждая вторая — пустой список.
- **`open()` считает путь от текущей папки терминала**, а не от папки скрипта. Отсюда `FileNotFoundError` при запуске из корня проекта.

## Две опечатки в методичке

В `advanced.py` методичка даёт `return base  exponent` без оператора, правильно `base ** exponent`. В последнем `main.py` раздела 5 не закрыта кавычка у строки «Неизвестная операция». Обе дают `SyntaxError` ещё до запуска, и никакой `try/except` их не ловит: синтаксис проверяется раньше, чем начинает выполняться код.

## Модуль и пакет

- **Модуль** это файл `.py`. Любой.
- **Пакет** это папка с файлом `__init__.py` внутри. Файл может быть пустым, важно его наличие.

`calculator_modules/arithmetic.py` и `calculator_modules/operations/basic.py` содержат одни и те же функции. Это не ошибка, так идёт методичка: сначала показывают модуль, потом тот же код в пакете. В настоящем проекте дублировать так не стали бы.

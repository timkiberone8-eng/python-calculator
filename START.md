# Начни отсюда

Это учебный проект группы 14+ «Python», KIBERone Ярославль. Здесь лежит то, что группа написала на занятиях: калькулятор, который постепенно превращается из одного файла в настоящий проект с модулями, обработкой ошибок и сохранением данных.

Страница для тех, кто пропустил занятия или только приходит в группу. Внутри порядок действий, чтобы прийти на занятие подготовленным.

**Сколько это занимает:** установка программ минут двадцать, разбор проекта полтора часа. Можно в два захода, не обязательно за один вечер.

**Что это не заменяет:** самостоятельный разбор дает понимание, что происходит в коде группы. Разобранное на занятиях он не заменяет, и это нормально. Задача скромнее: прийти не с нуля.

## Шаг 1. Поставить три программы

| Что | Откуда | На что обратить внимание |
|---|---|---|
| Python | python.org, раздел Downloads | при установке поставить галочку **Add python.exe to PATH**, она внизу первого окна |
| VS Code | code.visualstudio.com | это редактор, в нем пишут код |
| Git | git-scm.com | все галочки по умолчанию, ничего менять не нужно |

Галочка у Python важнее всего остального на этой странице. Без нее компьютер не будет понимать команду `python`, и дальше ничего не заработает. Если забыл, установку можно запустить заново и выбрать Modify.

Потом в VS Code слева иконка с квадратиками (Extensions), в поиске набрать `Python`, поставить расширение от Microsoft.

**Проверка, что все встало.** Открыть VS Code, вверху меню Terminal, пункт New Terminal, и по очереди набрать:

```bash
python --version
git --version
```

Должны ответить номерами версий, например `Python 3.13.12`. Если вместо этого открылся магазин приложений или написано, что команда не найдена, значит галочка PATH не стояла. Переустановить Python с галочкой и открыть терминал заново: старое окно терминала о новых программах не знает.

## Шаг 2. Скачать проект

Способ с Git, он же правильный:

```bash
git clone https://github.com/timkiberone8-eng/python-calculator.git
cd python-calculator
```

Если Git пока не встал, можно без него: зеленая кнопка **Code** вверху страницы проекта, пункт **Download ZIP**, распаковать в удобную папку. Дальше все то же самое, кроме команд с историей шагов.

Открыть папку в VS Code: меню File, пункт Open Folder, выбрать папку проекта.

## Шаг 3. Запустить

В терминале VS Code, находясь в папке проекта:

```bash
python main.py
```

Программа спросит два числа и операцию. Попробуй по очереди:

- `5`, `3`, `сложение` даст `Результат: 8.0`
- `5`, `0`, `деление` даст «Ошибка: деление на ноль невозможно!» и не упадет
- `привет` вместо числа даст «Ошибка: введено не число!»
- `-9`, потом любое второе число, потом `квадратный корень` даст «Ошибка: корень из отрицательного числа не определён». Второе число программа спрашивает всегда, даже когда оно не нужно: это известная недоделка, чинить ее будем вместе

Три последних случая это и есть смысл уроков 2 и 3: программа не ломается от неправильного ввода, а объясняет, что не так.

**Важно про кнопку запуска.** В VS Code есть зеленый треугольник Run. Для этого проекта он не подходит: вывод уходит в панель, куда нельзя печатать, и программа падает на первом же вопросе с ошибкой `EOFError`. Запускать командой в терминале.

## Шаг 4. Пройти по шагам занятий

Проект собран так, что каждое сохранение в истории это один шаг занятия, и на каждом шаге программа работает. Посмотреть список:

```bash
git log --oneline
```

Снизу вверх это путь группы с первого занятия. Перемотать проект на любой шаг:

```bash
git checkout <первые буквы и цифры строки>
python main.py
git checkout main
```

Последняя команда возвращает проект в конец, к самой свежей версии. Делай так после каждого просмотра, иначе запутаешься, где находишься.

Если скачивал ZIP, истории нет, но есть та же последовательность файлами:

| Шаг | Что смотреть | Что нового |
|---|---|---|
| 1 | `calculator.py` | весь калькулятор одним файлом |
| 2 | `calculator_modules/arithmetic.py`, `main.py` | код разнесен по файлам, каждый файл это модуль |
| 3 | `calculator_modules/operations/` | папка с `__init__.py` это пакет, внутри несколько модулей |
| 4 | `main.py`, блок `try` | программа перестала падать от неправильного ввода |
| 5 | `main.py`, класс `NegativeNumberError` | своя собственная ошибка, про правила нашей программы |
| 6 | `urok4/read_example.py`, `write_note.py` | чтение и запись файлов |
| 7 | `urok4/books_csv.py` | таблица в файле, формат CSV |
| 8 | `urok4/my_library.py` | программа, которая помнит данные после закрытия |

Читай не только код, но и комментарии в нем. Они написаны как объяснение, а не как пометки для себя.

## Если что-то не работает

| Что видно | В чем дело | Что сделать |
|---|---|---|
| `python` не найден, открылся магазин приложений | не стояла галочка Add python.exe to PATH | переустановить Python с галочкой, открыть новое окно терминала |
| `EOFError: EOF when reading a line` | запуск зеленой кнопкой вместо терминала | набрать `python main.py` в терминале |
| `FileNotFoundError: example.txt` в файлах урока 4 | программы урока 4 ищут файл рядом с собой | сначала `cd urok4`, потом `python read_example.py` |
| `ModuleNotFoundError` | запуск не из той папки | вернуться в папку проекта командой `cd`, запускать `python main.py` оттуда |

Если застрял дольше чем на двадцать минут, не сиди: запиши, что именно написано на экране, и покажи на занятии. Умение прочитать сообщение об ошибке и есть половина программирования, этому мы как раз учимся.

# Проект «Книжная библиотека»

Межурочный проект первого блока курса. Даётся после уроков 0–4, делается **в своём репозитории**, а не в этом. Здесь — только задание и критерии.

Консольная программа, которая хранит коллекцию книг: добавляет, показывает, ищет, редактирует, удаляет и **не теряет данные при выходе**.

## Что должно уметь

| № | Функция | Что проверяем |
|---|---|---|
| 1 | Добавить книгу: название, автор, год, жанр | книга появляется в списке |
| 2 | Показать все книги | пустая библиотека говорит «пусто», а не молчит |
| 3 | Найти книгу по названию или автору | находит по куску слова, регистр не важен |
| 4 | Изменить книгу | пустой ввод оставляет старое значение |
| 5 | Удалить книгу | неверный номер не роняет программу |
| 6 | Сохранение в CSV и загрузка при старте | закрыл, открыл заново — книги на месте |
| 7 | Обработка ошибок | ввёл букву вместо номера — программа объясняет, а не падает |
| 8 | История в Git | не один коммит в конце, а по коммиту на функцию |

## Как книга хранится в памяти

Каждая книга — словарь, вся библиотека — список словарей:

```python
library = []

book = {
    "title": "1984",
    "author": "Джордж Оруэлл",
    "year": "1949",
    "genre": "антиутопия",
}
library.append(book)
```

Словарь вместо четырёх отдельных списков — потому что данные одной книги лежат вместе и не могут разъехаться.

## Три шага, по одному на заход

**Шаг 1. Структура и меню.** `library = []`, функции `add_book` и `show_books`, цикл `while True` с меню и пунктом «Выход». На этом шаге данные живут только в памяти и пропадают при выходе — так и должно быть.

**Шаг 2. Поиск, редактирование, удаление.** Три функции и три новых пункта меню. Поиск делается по `query.lower() in book["title"].lower()` — тогда «ору» найдёт Оруэлла.

**Шаг 3. Файл и ошибки.** `save_library(filename)` и `load_library(filename)` через модуль `csv`, загрузка при старте, сохранение перед выходом. Плюс `try/except` там, где пользователь вводит номер книги.

## Три места, где это ломается у всех

1. **`open()` без `encoding="utf-8"`.** В методичке его нет. На школьной машине Windows возьмёт cp1251, и файл перестанет быть UTF-8. Писать `encoding="utf-8"` в каждом `open()`.
2. **`csv.writer` без `newline=""`.** В файл попадёт лишний перевод строки, и при чтении между книгами появятся пустые строки. Проверено: две записанные строки читаются как четыре.
3. **Из CSV всё приходит текстом.** Год вернётся строкой `"1949"`, а не числом. Если его надо сравнивать — `int(year)` внутри `try`.

## Что считается сделанным

Программу запустили, добавили две книги, вышли пунктом меню, запустили снова — книги на месте. В репозитории не меньше трёх коммитов с внятными сообщениями, `__pycache__` в коммиты не попал.

Образцы приёмов: `urok4/my_library.py` в этом репозитории — тот же принцип на трёх полях вместо четырёх.

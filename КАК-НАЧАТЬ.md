Эта ветка нужна одному: чтобы новый ученик сел и продолжил вместе со всеми, а не догонял два пропущенных занятия у доски.

Здесь лежит калькулятор ровно в том состоянии, с которым группа закончила занятие 2.

## Что уже сделано

- калькулятор разнесён по модулям: `calculator_modules/arithmetic.py` и `advanced.py`
- есть `try` и `except`, программа не падает ни от буквы вместо числа, ни от деления на ноль
- `divide` делит честно, ошибку бросает Python

- файла `__init__.py`: папка с модулями пока просто папка, а не пакет
- блока `else`
- своего исключения и его ловли

Это не забыли, это сегодняшняя работа.

## Как забрать себе

Самый простой способ: открыть папку учебника рядом со своей папкой и скопировать в неё `main.py` и папку `calculator_modules`. Обычным копированием, мышкой.

Способ через терминал, если своей папки ещё нет:

```bash
git clone -b start-zanyatie-3 --single-branch https://github.com/timkiberone8-eng/python-calculator.git moy-kalkulyator
cd moy-kalkulyator
```

После этого папка связана с репозиторием преподавателя, а тебе нужна своя. Отвязать и начать собственную историю:

```bash
rm -rf .git
git init
git add .
git commit -m "Мой калькулятор: старт"
```

`rm -rf .git` удаляет только служебную папку с историей преподавателя. Твои файлы остаются на месте, и дальше история будет твоя с первого коммита.

## Проверь, что работает, до начала занятия

```bash
python main.py
```

Введи 10, 2 и `сложение` — должно напечатать `Результат: 12.0`.
Потом 5, 0 и `деление` — должно напечатать `Ошибка: деление на ноль невозможно!`, а не упасть.

Если оба ответа такие, ты на одном уровне с группой и можешь работать дальше со всеми.
